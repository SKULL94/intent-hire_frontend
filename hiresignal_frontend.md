# HireSignal — Flutter Frontend Specification

## Overview

HireSignal is a Flutter mobile app that shows developers which companies are likely hiring in their tech stack — before jobs are posted. The app connects to a FastAPI backend (for writes) and Supabase (for reads + realtime + auth), presenting scored company matches based on hiring intent signals and tech-stack alignment.

**Architecture: Clean Architecture + BLoC.** Each feature is a self-contained slice with `data/`, `domain/`, and `presentation/` layers. Business logic flows through usecases; UI state flows through BLoCs; dependencies are resolved via `get_it`.

| Language | Dart 3.5+ | Flutter's native language |
| Architecture | Clean Architecture | Testable layers, swap data sources without touching UI |

| Functional error handling | `dartz` 0.10+ | `Either<Failure, T>` return types from usecases |
| Local Storage | `shared_preferences` + `hive_flutter` | Settings + offline cache |
| Models | `json_annotation` + `json_serializable` | Code-gen DTOs |
| Charts | `fl_chart` 0.69+ | Signal trend visualization |
| Notifications | Firebase Cloud Messaging | Phase 2 — push on new high-score match |
| Design | Material 3 | Adaptive, theming |

## Clean Architecture at a Glance

```
┌─────────────────────────────────────────────┐
│                 Presentation                │   Widgets, Pages, BLoCs
│   (Pages ─▶ BLoC ─▶ UseCase)                │
└──────────────────┬──────────────────────────┘
                   │ depends on
                   ▼
┌─────────────────────────────────────────────┐
│                   Domain                    │   Pure Dart. No Flutter imports.
│   (Entities, UseCases, abstract Repos)      │
└──────────────────▲──────────────────────────┘
                   │ implemented by
                   │
┌──────────────────┴──────────────────────────┐
│                    Data                     │   Models (DTOs), RemoteDataSources,
│   (RepositoryImpl ─▶ RemoteDataSource)      │   RepositoryImpls, Mappers
└─────────────────────────────────────────────┘
```

**Rules:**
- `domain/` has no imports from `data/` or `presentation/` or `supabase_flutter`.
- `data/` imports `domain/` for interface contracts; implements them.
- `presentation/` imports `domain/` for usecases and entities; never imports `data/` directly.
- Usecases return `Future<Either<Failure, T>>`. BLoCs catch failures explicitly.

## Core — Network Layer

The `http` package has no interceptor framework, so we write a minimal wrapper that attaches the Supabase JWT and normalizes errors.

```dart
// lib/core/network/api_client.dart

@lazySingleton
class ApiClient {
  final http.Client _client;
  final SupabaseClient _supabase;

  ApiClient(this._client, this._supabase);

  Future<Map<String, String>> _headers({bool json = true}) async {
    final token = _supabase.auth.currentSession?.accessToken;
    return {
      if (json) 'Content-Type': 'application/json',
      if (token != null) 'Authorization': 'Bearer $token',
    };
  }

  Uri _uri(String path, [Map<String, dynamic>? query]) => Uri.parse(
        '${AppConstants.apiBaseUrl}$path',
      ).replace(queryParameters: query?.map((k, v) => MapEntry(k, '$v')));

  Future<dynamic> get(String path, {Map<String, dynamic>? query}) async {
    final resp = await _client.get(_uri(path, query), headers: await _headers(json: false));
    return _handle(resp);
  }

  Future<dynamic> post(String path, {Object? body}) async {
    final resp = await _client.post(_uri(path), headers: await _headers(), body: jsonEncode(body));
    return _handle(resp);
  }

  Future<dynamic> patch(String path, {Object? body}) async {
    final resp = await _client.patch(_uri(path), headers: await _headers(), body: jsonEncode(body));
    return _handle(resp);
  }

  dynamic _handle(http.Response resp) {
    if (resp.statusCode >= 200 && resp.statusCode < 300) {
      return resp.body.isEmpty ? null : jsonDecode(resp.body);
    }
    if (resp.statusCode == 401) throw AuthException(resp.body);
    if (resp.statusCode >= 500) throw ServerException(resp.body);
    throw ServerException(resp.body);
  }
}
```

```dart
@lazySingleton
class AppRouter {
```

```dart
// lib/features/matches/data/datasources/matches_remote_datasource.dart

@lazySingleton
class MatchesRemoteDataSource {
  final SupabaseClient _supabase;
  final ApiClient _api;
  MatchesRemoteDataSource(this._supabase, this._api);

  Stream<List<MatchModel>> watchMatches(String userId) => _supabase
      .from('matches')
      .stream(primaryKey: ['id'])
      .eq('user_id', userId)
      .order('score', ascending: false)
      .map((rows) => rows.map((r) => MatchModel.fromJson(r)).toList());

  Future<void> refreshMatches() => _api.post('/api/v1/matches/refresh');

  Future<void> updateStatus(String matchId, String status) =>
      _api.patch('/api/v1/matches/$matchId', body: {'status': status});
}
```

```dart
// lib/features/matches/data/repositories/matches_repository_impl.dart

@LazySingleton(as: MatchesRepository)
class MatchesRepositoryImpl implements MatchesRepository {
  final MatchesRemoteDataSource _remote;
  MatchesRepositoryImpl(this._remote);

  @override
  Stream<Either<Failure, List<Match>>> watchMatches(String userId) {
    return _remote.watchMatches(userId)
      .map<Either<Failure, List<Match>>>(
        (list) => Right(list.map((m) => m.toEntity()).toList()),
      )
      .handleError((e) => Left(ServerFailure(e.toString())));
  }

  @override
  Future<Either<Failure, void>> refreshMatches() async {
    try {
      await _remote.refreshMatches();
      return const Right(null);
    } on AuthException catch (e) { return Left(AuthFailure(e.message ?? 'Unauthorized')); }
      on ServerException catch (e) { return Left(ServerFailure(e.message ?? 'Server error')); }
  }

  @override
  Future<Either<Failure, void>> updateStatus(String id, MatchStatus status) async {
    try {
      await _remote.updateStatus(id, status.name);
      return const Right(null);
    } on ServerException catch (e) { return Left(ServerFailure(e.message ?? 'Server error')); }
  }
}
```

```dart
// lib/features/matches/presentation/bloc/matches_bloc.dart

@injectable
class MatchesBloc extends Bloc<MatchesEvent, MatchesState> {
  final WatchMatches _watch;
  final RefreshMatches _refresh;
  final UpdateMatchStatus _updateStatus;
  StreamSubscription? _sub;

  MatchesBloc(this._watch, this._refresh, this._updateStatus) : super(const MatchesInitial()) {
    on<MatchesSubscribed>(_onSubscribed);
    on<MatchesRefreshRequested>(_onRefresh);
    on<MatchStatusUpdated>(_onStatusUpdated);
    on<_MatchesReceived>((e, emit) => emit(MatchesLoaded(e.matches)));
    on<_MatchesErrored>((e, emit) => emit(MatchesError(e.failure.message)));
  }

  Future<void> _onSubscribed(MatchesSubscribed e, Emitter<MatchesState> emit) async {
    emit(const MatchesLoading());
    await _sub?.cancel();
    _sub = _watch(e.userId).listen((either) {
      either.fold(
        (failure) => add(_MatchesErrored(failure)),
        (matches) => add(_MatchesReceived(matches)),
      );
    });
  }

  Future<void> _onRefresh(MatchesRefreshRequested e, Emitter<MatchesState> emit) async {
    final res = await _refresh(const NoParams());
    res.fold((f) => emit(MatchesError(f.message)), (_) {});
  }

  Future<void> _onStatusUpdated(MatchStatusUpdated e, Emitter<MatchesState> emit) async {
    await _updateStatus(UpdateMatchStatusParams(e.matchId, e.status));
    // Supabase stream will emit the updated row — no manual emit needed.
  }

  @override
  Future<void> close() async { await _sub?.cancel(); return super.close(); }
}
```

## Supabase Integration

The Supabase client is injected via DI; raw calls are confined to data layer datasources.

### Auth (used by `AuthRemoteDataSource`)

```dart
@lazySingleton
class AuthRemoteDataSource {
  final SupabaseClient _supabase;
  AuthRemoteDataSource(this._supabase);

  Future<AuthUserModel> signInWithEmail(String email, String password) async {
    final res = await _supabase.auth.signInWithPassword(email: email, password: password);
    if (res.user == null) throw const AuthException('Login failed');
    return AuthUserModel.fromSupabaseUser(res.user!);
  }

  Future<void> signInWithGoogle() => _supabase.auth.signInWithOAuth(
        OAuthProvider.google,
        redirectTo: 'io.hiresignal.app://callback',
      );

  Future<void> signOut() => _supabase.auth.signOut();

  Stream<AuthUserModel?> watchAuthState() =>
      _supabase.auth.onAuthStateChange.map((e) =>
          e.session?.user == null ? null : AuthUserModel.fromSupabaseUser(e.session!.user));
}
```

### Realtime read (used by `MatchesRemoteDataSource` — shown earlier)

Reads flow through Supabase realtime streams and standard `select` calls. Writes go through FastAPI via `ApiClient`. This split is intentional: Supabase handles RLS for reads; FastAPI handles business logic + Claude calls for writes.

## Testing Strategy

| Layer | What to test | How |
|---|---|---|
| Domain usecases | Pure logic; return `Either<Failure, T>` | `mocktail` for repository mocks |
| Repositories | Mapping model → entity; error translation | `mocktail` for datasource mocks |
| BLoCs | Event → state transitions | `bloc_test` |
| Widgets | Golden/pump tests for `MatchCard`, `ScoreBadge` | `flutter_test` |
| Datasources | Not unit-tested in Phase 1 (integration-only) | Deferred |

Example BLoC test:

```dart
blocTest<MatchesBloc, MatchesState>(
```
